# HOLP — MVP

HOLP és una aplicació mòbil per organitzar la convivència: tasques domèstiques, agenda compartida, disponibilitat i despeses en un mateix lloc.

## Funcions incloses

- Resum diari de la llar
- Tasques completables i filtres
- Repartiment visible de la càrrega
- Agenda compartida amb tres nivells de privacitat
- Disponibilitat per membre
- Despeses compartides i càlcul de saldos
- Invitació de membres
- Dades persistents al dispositiu amb localStorage
- Instal·lació com a PWA i funcionament offline

## Provar localment

Obre `index.html` amb un servidor web estàtic. Per exemple, amb VS Code pots utilitzar Live Server.

## Publicació

El workflow `.github/workflows/pages.yml` publica automàticament a GitHub Pages quan Pages està configurat amb **GitHub Actions** com a font.

> Aquesta és una versió de validació. Encara no inclou comptes reals, sincronització entre dispositius, notificacions push ni backend compartit.
